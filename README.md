# Compiler for MicroJava
This project is fully functional compiler for MicroJava programming language. It supports all language characteristics except OOP designs. Compiler includes syntax and semanthic analysis as well. 

# How to run the project
* Write your source code in `test/program.mj` file or any other `.mj` file
* Write your input data in `test/input.txt` file
* Specify path to your source code file in `Compiler` class
* Run `build.xml` Ant script with `compile` target to compile your source code and generate bytecode for MicroJava VM
* Run `build.xml` Ant script with `run` target to run your generated bytecode in MicroJava VM
